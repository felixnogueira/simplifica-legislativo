Status do Backend

O Simplifica Legislativo é uma plataforma democrática que permite ao cidadão comum ler, compreender e acompanhar os projetos de lei em tramitação na Câmara dos Deputados. O objetivo é democratizar o acesso à informação legislativa, capacitando os cidadãos a tomarem decisões informadas e participarem ativamente da vida política do país.

Arquitetura Técnica

A plataforma foi desenvolvida combinando Python (FastAPI) no backend para processamento de dados e API REST, TypeScript (Angular) no frontend para uma interface responsiva e intuitiva, e RAG (Retrieval Augmented Generation) para inteligência artificial baseada em recuperação de informações contextuais.

Os dados legislativos são obtidos diretamente da API de Dados Abertos da Câmara dos Deputados, garantindo a procedência e atualização das informações.

Propósito e Filosofia

O Simplifica Legislativo nasceu da necessidade de tornar o conteúdo legislativo compreensível a todos. Muitos cidadãos encontram dificuldade em entender o teor e o impacto das proposições legislativas devido à complexidade técnica dos termos utilizados, tendo dificuldade então de entender exatamente o que acontece no contexto político, além de serem diariamente bombardeados por notícias falsas, vídeos curtos sem fontes e conteúdo digital com objetivo de influenciar o cidadão a formar uma opinião específica. Nossa plataforma utiliza RAG para traduzir essa linguagem para um formato mais compreensível, sem perder a fidelidade ao conteúdo original, garantido que o usuário possa realizar pesquisas sobre projetos de lei e pensar por si mesmo na hora de formar uma opinião política.

Compromisso com a verdade: Todas as informações fornecidas são baseadas exclusivamente nos documentos oficiais da Câmara. Utilizamos indexação de documentos vetorizados para extrair e contextualizar as informações, sem adulteração ou acréscimo de dados externos. Cada resposta é acompanhada das fontes originais, permitindo que o usuário verifique a procedência das informações.

Abordagem Técnica e Limitações

Em um cenário ideal, todo o processamento de linguagem natural seria realizado por uma LLM (Large Language Model) executada localmente, garantindo total privacidade e isolamento de informações externas. No entanto, a infraestrutura necessária para hospedar uma LLM local com performance adequada representa um custo significativo, inviável para a atual fase desse projeto acadêmico.

Para contornar essa limitação mantendo a viabilidade do projeto, adotamos uma arquitetura híbrida que combina ferramentas gratuitas e open-source com APIs comerciais de alta qualidade. A seguir, detalhamos as tecnologias utilizadas:

LLM Local (Ollama)

Modelo de linguagem executado localmente na máquina do desenvolvedor para processamento inicial dos documentos da Câmara. Esta etapa garante que o conteúdo original seja preservado antes de qualquer processamento externo.

Qdrant Vector Database

Banco de dados vetorial de alto desempenho para armazenamento e recuperação semântica dos documentos legislativos. Os documentos são transformados em representações vetoriais (embeddings) que permitem busca por similaridade contextual, não apenas por palavras-chave.

FastAPI

Framework web moderno e de alta performance para construção da API REST do backend. Fornece validação automática de dados, documentação interativa (Swagger/OpenAPI) e suporte nativo a operações assíncronas.

Angular

Framework frontend mantido pelo Google para construção de Single Page Applications (SPAs). Oferece uma estrutura robusta com componentes reutilizáveis, injeção de dependências e roteamento, garantindo uma experiência de usuário fluida e responsiva.

NG-ZORRO

Biblioteca de componentes UI para Angular baseada no Ant Design. Fornece um conjunto completo de componentes pré-estilizados e acessíveis, acelerando o desenvolvimento e garantindo consistência visual na interface.

Provedores de LLM

O sistema utiliza múltiplos provedores de modelos de linguagem para geração de respostas contextualizadas: Ollama (execução local), Workers AI (Cloudflare), OpenCode Zen, Gemini (Google) e Groq. O sistema tenta automaticamente o provedor disponível, garantindo redundância e disponibilidade. Os modelos recebem os documentos relevantes recuperados do Qdrant e geram explicações em linguagem acessível, mantendo-se estritamente fiéis ao conteúdo dos documentos originais.
